LangGraph is a library designed for building stateful, multi-actor applications with LLMs. By representing agentic workflows as graphs (nodes and edges), LangGraph provides developers with fine-grained control over execution flow, state management, and human-in-the-loop interactions. In many complex agent scenarios, a system needs to perform parallel operations where the number of parallel tasks is determined dynamically at runtime. For example, a planner agent might decompose a complex query into an arbitrary number of sub-questions, each requiring an independent search. To support this pattern, LangGraph provides the Send API.

The Send API enables dynamic fan-out or map-reduce operations. Unlike static parallel execution where paths are hardcoded in the graph definition, the Send API allows conditional edges to return one or more Send objects. Each Send object specifies a target node and a specific state to pass to that node. For instance, in a planner-researcher architecture, a conditional edge following the planner node can inspect the list of sub-tasks in the graph state and return a list of Send("researcher_node", {"current_sub_task": task}) objects. LangGraph then automatically executes the researcher_node for each sub-task in parallel.

When parallel branches complete, they must converge back (fan-in) to a single node, such as an aggregator or writer. LangGraph manages this state convergence through reducers. By defining a field in the state with a reducer function, such as Annotated[list, operator.add], the outputs of all parallel branches are automatically combined. Without reducers, parallel writes to the same state key would result in conflicts or overwrites, where only the last completed branch's output is preserved. The combination of the Send API and state reducers makes LangGraph exceptionally powerful for scaling complex retrieval and reasoning tasks.
